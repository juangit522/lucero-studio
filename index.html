xG Predictor Modelo de predicción de fútbol

Aplicación web interactiva que analiza métricas de Expected Goals (xG) y estadísticas de rendimiento para calcular probabilidades en tiempo real de las principales ligas europeas (LaLiga, Premier League, Bundesliga, Ligue 1). Cuenta con automatización diaria de datos en segundo plano mediante GitHub Actions.

  • Python
  • Streamlit
  • Pandas
  • GitHub Actions
  • Web Scraping
